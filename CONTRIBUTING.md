# Contributing

Issues and focused pull requests are welcome. Do not include proprietary source,
generated binaries, credentials, personal data or unrelated product code.

External changes are reviewed by the project maintainer before merge. Changes to
the source, build scripts, workflows or SignPath configuration receive the same
review because all of them affect release provenance. Contributions are provided
under the repository's MIT license.

Run the checks on Windows before opening a pull request:

```powershell
.\test.ps1
```

Report sensitive security problems using the process in [SECURITY.md](SECURITY.md).
